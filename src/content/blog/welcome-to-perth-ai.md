## Adding a post

Every post is a single markdown file in `src/content/blog/`. Copy this file, rename it — the
filename becomes the URL, so `evals-are-the-hard-part.md` becomes `/blog/evals-are-the-hard-part` —
and edit the bit between the `---` lines at the top:

- **title** — shows up as the heading and the browser tab
- **description** — the one-line summary on the blog index and in link previews
- **date** — `YYYY-MM-DD`, used for sorting
- **author** — optional, defaults to "Perth AI"
- **tags** — optional list, shown as little labels
- **draft** — set to `true` and it won't appear on the live site

Then write below it in normal markdown.
